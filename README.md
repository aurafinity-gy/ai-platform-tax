# Aurafinity AI Tax Platform

Canadian personal and corporate tax preparation, research, and review domain application.

**Status:** architecture-first bootstrap; synthetic data only. Not a tax filing service.

See [AGENTS.md](AGENTS.md), [architecture](docs/architecture.md), and [implementation plan](docs/implementation-plan.md). The platform consumes versioned Foundation contracts without duplicating its orchestration, model gateway, knowledge retrieval, tenancy, or evidence lifecycle internals.

No real taxpayer information, live CRA filing, unattended advice publication, or production processing is authorized.
